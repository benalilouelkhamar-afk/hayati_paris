# Photos des produits

Le site utilise les photos `.jpg` de ce dossier (optimisées pour le web).
Les originaux envoyés (PNG) sont conservés dans `images/originaux/`.

- Chaque produit du tableau `PRODUCTS` (dans `assets/js/main.js`) utilise `images/produits/<id>.jpg`.
- Pour ajouter des photos à la galerie d'un produit : `<id>-2.jpg`, `<id>-3.jpg`, `<id>-4.jpg`
  (ex. `ensemble-mandarin-2.jpg`).
- Photo de la boutique : `images/boutique.jpg` (sinon une illustration est affichée).
