# HAYATI Paris — site vitrine (front-end)

Site statique HTML / CSS / JS, sans backend :

- `index.html` — accueil
- `collection.html?cat=nouveautes|ensembles|robes|chemises|blazers` — catégorie avec filtres
- `produit.html?id=<produit>` — fiche produit (galerie, couleurs, tailles, panier, commande WhatsApp)

Pour tester en local : ouvrir `index.html` dans un navigateur, ou `python3 -m http.server`.

- Photos : voir `images/produits/LISEZ-MOI.md`.
- Numéro WhatsApp : constante `WHATSAPP` en haut de `assets/js/main.js`.
- Produits et prix : tableau `PRODUCTS` dans `assets/js/main.js`.
